# Découvertes et outils

Une sélection de logiciels et projets intéressants, avec une description volontairement courte et leur lien officiel.

## 🖱️ Périphériques et souris

- **[InputLab](https://github.com/moneks1106-code/InputLab)** — Utilitaire Windows pour analyser la régularité des signaux reçus d'une souris ou d'une manette, le polling rate, les connexions USB et certains paramètres d'alimentation. **Attention :** le dépôt distribue un programme compilé sans publier son code source.
- **[OpenMouse](https://openmouse.app/)** ([GitHub](https://github.com/OpenMouse-Project/openmouse)) — Interface open source qui permet de configurer certaines souris compatibles directement dans un navigateur Chromium : DPI, fréquence d'interrogation et autres réglages selon le modèle. La compatibilité varie selon les périphériques.

## 🎮 Performances et jeux

- **[SCSKiller](https://github.com/BlueHeisenberg/SCSKiller)** — Projet open source pour Windows visant à réduire les saccades liées à la compilation des shaders en préparant leur cache avant de lancer certains jeux. L'efficacité dépend du jeu et des pilotes ; les fonctions d'enregistrement peuvent présenter un risque avec les systèmes anti-triche.

---

> **Précaution :** ces descriptions résument la documentation des auteurs, pas un audit de sécurité indépendant ni une garantie de performance. Consulte les pages officielles, vérifie la compatibilité et évite de désactiver les protections de Windows ou des jeux pour utiliser un outil.
