# Guides de dépannage

Bienvenue dans la section des tutoriels **MyTechNotes**.

Ici, tu trouveras des procédures pour diagnostiquer des problèmes et tester des solutions sur Windows, League of Legends et d'autres logiciels.

## Comment consulter un guide ?

1. Choisis un tutoriel dans la liste ci-dessous.
2. Vérifie que les symptômes et la configuration correspondent à ton problème.
3. Lis les précautions et effectue les étapes dans l'ordre.
4. Si la solution ne fonctionne pas, restaure les réglages modifiés lorsque c'est indiqué.
